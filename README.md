# MRD (Mythology Random Defense)

워크래프트3 커스텀 맵 "나루토 랜덤 디펜스"/"원피스 랜덤 디펜스"의 게임 시스템(등급 체계, 조합, 자원, 웨이브, 전투 공식)을 계승하고, 세계관/캐릭터를 세계 신화 오리지널 IP로 재구성한 유니티 디펜스 게임입니다.

## 세계관
오래전 봉인되었던 여러 신화의 판테온들이 하나의 균열 세계에서 동시에 깨어난다. 플레이어는 무작위로 소환되는 신·영웅·괴물들을 모아 진영을 조합해 세계를 침식하는 "혼돈"의 무리를 막아낸다.

## 진영 (Faction)
- 올림포스 (그리스 신화)
- 아스가르드 (북유럽 신화)
- 라의 왕좌 (이집트 신화)
- 구주 (동양 신화)
- 심연의 서고 (메소포타미아 신화)
- 숲의 맹약 (켈트 신화)

## 등급 체계 (Rarity)
노말 → 매직 → 레어 → 유니크 → 전설 → 히든 → 엘리트 → 리미트 → 에픽 → 인피니티 → 창조 (+ 스페셜)

현재는 노말~히든까지 유닛 콘텐츠를 제작하며, 상위 등급(엘리트~창조·스페셜)은 확장을 위해 데이터 구조에만 정의되어 있습니다.

## 자원
- 골드: 웨이브 처치 보상, 노말/매직 소환(가챠)에 사용
- 보석: 랭크 미션 보상, 상급 소환 및 상위 등급 조합 재료
